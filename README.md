# Advanced Calculator

A responsive calculator for everyday arithmetic and common scientific operations, built with HTML, CSS, and vanilla JavaScript.

## Features

- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Scientific functions (percentage, square, square root, reciprocal, sign change)
- Calculation history saved in local storage
- Light and dark themes with toggle
- Decimal input support
- Floating-point result rounding to prevent errors
- Division-by-zero and invalid input handling
- Responsive layout for all devices
- Real-time display updates

## How to Use

### Using the Mouse

1. **Enter Numbers** – Click the number buttons (0–9) to enter digits.

2. **Choose an Operation** – Click an operation button:
   - Click `+` for addition
   - Click `−` for subtraction
   - Click `×` for multiplication
   - Click `÷` for division

3. **Calculate** – Click `=` or press Enter to see the result.

4. **Clear** – Click `C` to clear everything and start over.

5. **Delete Last Digit** – Click the backspace button or press Backspace to remove the last digit.

6. **Use Scientific Functions** – Click extra buttons for advanced operations:
   - Click `x²` to square a number
   - Click `√` to find the square root
   - Click `1/x` to find the reciprocal
   - Click `±` to change the sign
   - Click `%` to calculate a percentage

7. **View History** – Open the history panel on the right to see your last 10 calculations. Click any calculation to use its result.

8. **Clear History** – Click the trash icon in the history panel to delete all calculations.

### Using the Keyboard

Press keys directly for faster entry:
- Press number keys (0–9)
- Press `+`, `-`, `*`, `/` for operations
- Press `.` for a decimal point
- Press `Enter` or `=` to calculate
- Press `Backspace` to delete
- Press `Escape` to clear all

### Change Theme

Click the moon icon in the top-right corner to switch between light and dark themes. Your preference is saved automatically.

## Getting Started

1. Clone or download this repository
2. Open `index.html` in a modern web browser
3. No build tools or installation required
4. No internet connection needed

## Data Storage

- Theme preference is saved locally
